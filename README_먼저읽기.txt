곰플레이어 로드나인 보스타이머 v2

기능
- 티토르 예시: 43시간 리젠
- 클레메티스 예시: 매주 월요일 12:30
- 여러 사람이 같은 URL에서 같은 데이터 공유
- 길드원 PIN: 컷 등록
- 관리자 PIN: 보스 추가/삭제
- 페이지를 열어둔 동안 10분/5분/1분/정각 브라우저 알림

기본 PIN
관리자 0000 / 길드원 1111
config.json에서 꼭 변경하세요.

실행
1. 폴더 주소창에 cmd 입력
2. python -m pip install -r requirements.txt
3. python -m uvicorn app:app --host 0.0.0.0 --port 8000
4. http://127.0.0.1:8000 접속

카카오톡 공유
127.0.0.1은 본인 PC에서만 보입니다. 단톡방에서 같이 쓰려면 인터넷 서버(Render/Railway/VPS 등)에 배포해야 합니다.

알림 주의
브라우저 알림은 페이지를 열어두고 권한을 허용해야 가장 안정적입니다. 휴대폰 완전 백그라운드 푸시는 별도 푸시 기능이 필요합니다.
